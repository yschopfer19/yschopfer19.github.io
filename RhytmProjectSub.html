Rhythm Project

A lane-based rhythm game built from scratch.

Demo

Features

Lane-based Gameplay

Notes scroll down multiple lanes and the player hits them in time with the music.

Hit Detection

Timing windows judge each hit — perfect, good, or miss — with immediate visual feedback.

Hold Notes

Sustained notes that require the player to hold a key for the full duration.

Custom Beatmap System

Beatmaps are loaded from custom files, making it easy to add new songs and patterns.

Structure

Click a folder to see what's inside.

src/

▸

All game logic and the main loop.

  • main.cpp — entry point, initialises the window and starts the game loop
  • Game.cpp — central loop: update, input, render
  • Lane.cpp — manages a single note lane and its active notes
  • Note.cpp — note movement, hold-note logic, lifetime
  • BeatmapParser.cpp — reads beatmap files and schedules notes
  • ScoreManager.cpp — tracks hits, misses, and combo

include/

▸

Header files for all core classes.

  • Game.h — declares the game state and main loop interface
  • Lane.h — lane width, key binding, note list
  • Note.h — note type (tap / hold), timing window, position
  • BeatmapParser.h — beatmap format definition and parser interface
  • ScoreManager.h — score, combo, and accuracy tracking

assets/

▸

Fonts, audio, and beatmap files.

  • fonts/ — UI font used for score and feedback text
  • sounds/ — hit sounds and background music tracks
  • beatmaps/ — custom beatmap files, one per song

Kept fully separate from code so songs and assets can be swapped without touching any source files.

SFML

▸

The only external dependency.

  • Graphics — window creation, sprite rendering, shapes
  • Audio — music playback and hit sound effects
  • Input — keyboard polling each frame
  • Clock — delta time for frame-rate independent movement

No game engine used, all gameplay systems are hand-built on top of SFML.
