Fitness Tracker

A cross-platform workout tracking app for iOS and Android.

Features

Authentication

Sign up and login via Supabase Auth. Session state managed with Riverpod, automatic redirect via GoRouter.

Workout Tracking

Start a workout, add exercises, log sets with weight, reps, and optional RPE. Finish and save to Supabase.

Statistics & Charts

Personal records per exercise, weekly volume as a line chart, and weight progression over time — powered by fl_chart.

Cross-Platform

One codebase for iOS and Android. Planned integration with Apple Health and Google Health Connect.

Navigation

GoRouter with auth-aware redirects. Unauthenticated users are always sent back to login, no manual checks needed.

Nutrition (Planned)

Food logging with nutritional values via a foods + nutrition_entries schema. Part of Phase 4 on the roadmap.

Structure

Click a folder to see what's inside.

core/

▸

App-wide infrastructure.

  • router/app_router.dart — GoRouter setup with auth redirect logic
  • router/go_router_refresh_stream.dart — bridges Supabase auth stream to GoRouter's refreshListenable
  • supabase/supabase_config.dart — loads URL and publishable key from .env

features/auth/

▸

Login, register, session handling.

  • auth_service.dart — signUp, signIn, signOut via Supabase client
  • auth_providers.dart — Riverpod providers for auth state stream and current user
  • presentation/login_screen.dart — login UI
  • presentation/register_screen.dart — register UI

features/workouts/

▸

Active workout flow and set logging.

  • data/workout_repository.dart — all Supabase queries: start/finish workout, add exercises, log and delete sets
  • domain/workout_providers.dart — ActiveWorkoutNotifier holds the in-progress workout state
  • presentation/workout_screen.dart — active workout UI with per-exercise set cards
  • presentation/exercise_picker_screen.dart — searchable exercise list from Supabase

features/statistics/

▸

Charts and personal records.

  • data/statistics_repository.dart — fetches PRs, weekly volume, and weight progression from Supabase
  • domain/statistics_providers.dart — FutureProviders with .family for per-exercise data
  • presentation/statistics_screen.dart — TabBar with PR list, volume chart, weight chart
  • presentation/volume_chart.dart — fl_chart line chart for sets per week
  • presentation/weight_chart.dart — fl_chart line chart for weight over time
  • presentation/pr_card.dart — personal record list per exercise

features/home/

▸

Main shell and dashboard.

  • home_screen.dart — bottom navigation shell with three tabs: Dashboard, Workout, Statistics
  • Dashboard shows summary cards: workouts this week, weight, calories, next session
  • Tab state managed with a lightweight Riverpod Notifier

Supabase Schema

▸

Database tables and relations.

  • profiles — user profile linked to auth.users
  • exercises — exercise library with name and muscle group
  • workouts — one row per session, with user_id and finished_at
  • workout_exercises — links a workout to exercises with order_index
  • sets — weight, reps, RPE per workout_exercise

Row Level Security on all tables — users can only read and write their own data.
